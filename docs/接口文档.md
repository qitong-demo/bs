本文档由 `scripts/export-openapi.mjs` 从运行中的后端自动生成，源描述见 [openapi.json](openapi.json)。

- OpenAPI 描述：`http://127.0.0.1:8080/v3/api-docs`

## 通用约定

统一返回结构：

```json
{ "code": 200, "message": "success", "data": {} }
```

分页返回结构（`data` 部分）：

```json
{ "current": 1, "size": 10, "total": 0, "records": [] }
```

| 状态码 | 含义 |
| --- | --- |
| 200 | 业务成功（`code` 为 200） |
| 400 | 参数校验失败或业务规则不满足，`message` 为中文提示 |
| 401 | 未登录或凭证失效 |
| 403 | 已登录但当前角色无权访问 |
| 500 | 服务器内部错误 |

鉴权：登录接口返回 `token`，后续请求携带 `Authorization: Bearer <token>`。

角色：`USER`（普通用户）、`STATION_ADMIN`（驿站管理员）、`PLATFORM_ADMIN`（平台管理员）、`SUPER_ADMIN`（超级管理员）。
