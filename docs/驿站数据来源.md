### 字段口径与边界

- `data_status = VERIFIED`：名称、地址、所属区域、开放时间、服务设施都能从来源逐条核对。
- `data_status = PARTIAL`：有字段来源未逐条给出（例如只给了名称与地址、没有服务设施），
  `data_note` 会逐项写明缺什么；服务设施若为来源对该批驿站的统一描述，也会在此说明。
- `servicesScope`：仅记录在生成的数据文件 `stations.json` 中用于溯源（`STATION` = 服务设施由来源逐站给出，
  `BATCH` = 来自来源对该批驿站的统一描述）；数据库与接口用 `data_status` 与 `data_note` 表达同样的边界。
- **服务项目规范化**：来源的服务内容文本按顿号/逗号/分号拆分为服务项目，去掉括号里的补充说明与「等」字，
  超过 15 字的描述性片段与超过 15 项的部分不计入服务项目
  （原始文本完整保留在 [station-sources.json](station-sources.json) 中）；服务项是预约时可选的最小单位，必须是短名称。
- `status`：来源发布时这些点位均在开放状态，因此统一记为 `OPEN`；**点位是否持续开放需要在使用前重新核实**。

### 坐标来源（派生数据，与来源字段分开记录）

公开来源**都不提供点位经纬度**，因此本项目的坐标是用**高德地图 Web 服务派生**的：

1. 先用驿站名称做 **POI 搜索**，逐条校验「区县一致性 + 名称相似度 + 地址相似度」，取最可信的一条（`geocode_source = AMAP_POI`）；
2. 校验不通过则回退到**详细地址地理编码**（`geocode_source = AMAP_GEOCODE`）；
3. 两者都失败则**保留空坐标**，不从名称猜测、不编造。

> 实测说明：仅看「有返回率」，POI 搜索是 100%——但会把「大悦城小哥驿站」与「万达小哥驿站」
> 匹配到同一个点。加上置信度校验后，可信命中率约 55%，其余 45% 走地址地理编码，坐标撞车归零。
> 这与论文里常用的「有结果就算命中」不同，属于更严格的口径。

本期结果：共 1342 条拿到坐标，去重后 1170 个不同坐标点；
其中 51 个坐标点被多条驿站共用（涉及 128 条），
另有 95 条因「行政区冲突」或「距城市中心过远」被丢弃、0 条没有坐标。

**坐标精度边界**：

- 坐标是**派生值**，用于地图展示与就近参考，**不能当作驿站的精确位置**；
- 名称泛化的驿站（例如只叫「暖新驿站」）与地址只到路口/社区级的记录，地理编码结果只能落到片区，误差可达数百米；
- 多条驿站共用同一坐标时，通常它们本就在同一栋楼或同一个院落，也可能是泛化名称被匹配到了同一个 POI；
- 需要精确定位时，仍应通过高德地图搜索驿站名称、或浙里办等官方渠道核对。

### 营业信息（营业时间 / 联系电话）

高德 POI 还提供 `biz_ext.open_time`（营业时间）与 `tel`（电话），系统会同步这两项：

| 规则 | 说明 |
| --- | --- |
| 营业时间优先级 | **以高德数据为准**；高德未提供具体营业时间的驿站，才回退到来源文本 |
| 联系电话优先级 | **来源文本优先**，高德只补来源没有给出的号码 |
| 校验 | 复用与坐标相同的三重校验（区县一致性 + 名称相似度 + 地址相似度），**只接受可信匹配**；营业时间还要求形如 `HH:mm-HH:mm` 或「24小时」，过滤掉明显不属于驿站的取值 |
| 来源标注 | `business_source`：`AMAP_POI`（营业时间与电话均来自高德）/ `AMAP_POI+SOURCE`（营业时间来自高德、电话来自来源）/ `SOURCE+AMAP_POI`（营业时间来自来源、电话来自高德）/ `SOURCE`；`business_synced_at` 记录同步日期 |
| 留痕 | 高德营业时间覆盖了来源原值时，`data_note` 会同时写明「营业时间以高德地图为准」与「来源原文的开放时间为「…」」，便于回查 |

> **高德不能提供什么**：高德 POI **没有**「服务设施」这类结构化字段（`type`/`tag` 只是
> 「生活服务 / 政府机构」这种粗分类），所以饮水、充电、热饭等服务项目**仍然只能来自公开来源文本**；
> 高德也**没有**「此刻是否营业」的实时状态字段，只能按营业时间本地推算。
> 营业时间与电话同样是**第三方数据**（来自商户认领与用户上报），不是驿站官方提供给平台的，
> 实测同一驿站两边可能不一致——例如「大悦城小哥驿站」来源写 8:30-22:00，高德给的是 10:00-22:00 的商场时间。

本期同步结果：营业时间以高德为准 386 条（其中 227 条覆盖了来源原值）、
高德未提供而回退来源文本 760 条；电话来自来源 0 条、高德补空 408 条。

**坐标不是来源给出的**，因此：

- 坐标来源记录在 `geocode_source` / `geocode_at` 两列，**不参与 `data_status` 的判定**；
- 每条坐标记录在 `data_note` 中追加「坐标为高德地图地理编码派生，非来源给出」；
- 来源未标注行政区的记录会用地理编码结果补齐 `area`，并在 `data_note` 注明「由高德地图补齐，非来源给出」；
- 地理编码原始结果缓存在仓库内的 `data/station-geocode.json`，重跑 `generate-station-data.mjs` 不会再次调用接口。

- 联系电话来源未提供，保持 `NULL`。
- `manager_id`：**演示配置**，1~4 号「小哥驿站」（杭州市）分配给演示账号 2（station_admin_01），
  用于验证驿站管理员的数据范围；该字段不属于公开来源内容。

## 五、复现方式

```powershell
# 1. 采集来源页面（杭州：保存到 tmp/station-sources/；其他城市：产出 tmp/city-sources/<city>.json）
#    来源地址见上方各城市的来源清单

node scripts/parse-station-sources.mjs

# 3. 合并多城市数据，生成 stations.json / stations.sql / 本文档 / docs/station-sources.json
node scripts/generate-station-data.mjs

# 4. 导入数据库并自检
powershell -ExecutionPolicy Bypass -File scripts/init-mysql.ps1 -User root -Password <密码> -Reset
```
