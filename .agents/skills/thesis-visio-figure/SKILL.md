# 论文 Visio 图表绘制

为哈尔滨信息工程学院本科毕业设计（论文）绘制**可编辑的 Visio 图**，并保证图表本身符合学校规范。

## 一、规范依据（务必先读）

规范分两层，**以论文模板批注为准**，模板未写明的部分查《本科生毕业设计（论文）撰写规范》。

### 1.1 论文模板《论文模板260205》批注（直接约束图表）

| 项目 | 要求 |
|---|---|
| 图序 | 按章编排，如第4章第1个图为“图4-1” |
| 图题格式 | 图序 + **半角空格** + 图名，图题置于**图下方** |
| 图题样式 | Word 中套用样式“图标题”：中文宋体、西文 Times New Roman、**五号**；居中；段前 0 磅、段后 5 磅；行距固定值 18 磅 |
| 图名 | **不允许使用标点符号** |
| 图片 | 居中，套用样式“图片样式”，单倍行距 |
| 续表 | 图不适用；表格续表表题为“表序号+半角空格+（续）” |
| 界面截图 | 必须清晰；**界面中时间必须落在毕设时间范围内** |
| 绘图规范 | 时序图、流程图、系统用例模型“参考《论文撰写规范》” |

### 1.2 《哈尔滨信息工程学院本科生毕业设计（论文）撰写规范》4.12 图

来源：https://www.greathiit.com/html/2020/consultation_0501/602.html

- 插图应与文字紧密配合，**文图相符，技术内容正确**；
- **线条匀称，图面整洁美观**；
- 每幅插图应有图序和图题，图序必须连续，不得重复或跳缺；
- 由若干分图组成的插图，分图用 a、b、c… 标序，分图名及代号意义以图注形式写在图题下方（先写分图名，另起行写代号意义）；
- 图可用计算机绘制；
- 坐标图：横坐标必须标注量与单位，坐标名置于图下方居中，五号宋体加黑。

> 该规范正文的正文行距（1.5 倍）等条目已被 2026 版论文模板批注取代（固定值 23 磅），**排版一律以模板批注为准**，绘制规范仍引用 4.12 条。

### 1.3 由此得到的硬性约束（生成前逐项确认）

1. **线条匀称** → 全图所有可见线条粗细一致（默认 0.75 磅），不用粗细线区分层级。
2. **图面整洁美观** → 任何文字不得与其他文字或图形边框重叠；文字不得被生命线、激活条压住。
3. **技术内容正确** → 参与者、调用顺序、接口路径、状态取值必须与源码/论文前文一致，禁止臆造。
4. **中文宋体 + 西文 Times New Roman** → Visio 中 `Font=Times New Roman`、`AsianFont=SimSun`。
5. **插入后字号可读** → 见 §3.2 换算，插入后图内文字不得小于小五（9 磅）。
6. 图题由 Word 承担，**图内不要重复写图名**。
7. 图内文字尽量少用标点（尤其不要句末标点），与“图名不允许使用标点符号”的取向一致。

## 二、工作流

1. **读规范**：确认 §1.3 的七条约束。
2. **读源码**：用 grep/read 核对接口路径、类名、状态取值、调用顺序。控制器注解（如 `@RequireRole`）、拦截器 `preHandle` 分支必须逐条对应用例。
3. **写图定义**：新建 `specs/<图号>.py`，只填数据（生命线、消息、组合片段、激活条、字号），不要改引擎。
4. **生成**：
   ```powershell
   & $py .agents/skills/thesis-visio-figure/scripts/build_sequence_vsdx.py `
       --spec .agents/skills/thesis-visio-figure/specs/figure_4_1_user_auth.py `
       --out-vsdx "output/论文/图4-1_用户认证与个人中心模块时序图.vsdx" `
       --out-png  "output/论文/图4-1_用户认证与个人中心模块时序图.png"
   ```
5. **自检**（必做，不通过就改，不要交付）：
   ```powershell
   & $py .agents/skills/thesis-visio-figure/scripts/check_figure.py `
       --vsdx "output/论文/图4-1_....vsdx" --spec .agents/skills/.../specs/figure_4_1_user_auth.py
   ```
6. **看预览**：用 `read_image` 打开 PNG，肉眼确认无重叠、无压线、留白均衡。**这一步不能省**——引擎自检查不出“观感”问题。

### 2.3 流程图（用 `build_flowchart_vsdx.py`）

生成流程图用 `scripts/build_flowchart_vsdx.py` + `specs/<图号>.py`；VSDX 打包与 PNG 预览复用 `build_sequence_vsdx.py` 里的通用工具箱。

**图元约定**（按国内论文流程图惯例）：

| kind | 图元 | Visio 几何 | 用途 |
|---|---|---|---|
| `term` | 圆角矩形（`Rounding=0.16`） | `GEOM_ROUNDRECT` | 开始 / 结束 |
| `io` | 平行四边形（顶边右移 0.22W） | `GEOM_PARALLELOGRAM` | 输入 / 输出 |
| `process` | 矩形 | `GEOM_RECT` | 处理 |
| `decision` | 菱形 | `GEOM_DIAMOND` | 判断 |

**连线写法**：

- `('v', src, dst, label)` 竖向箭头：端点按两框的下边/上边自动计算，`是` 标签自动放在箭头右侧；
- `('h', src, dst, label)` 横向箭头：端点按两框的右边/左边自动计算，`否` 标签自动放在箭头上方居中；
- `('poly', [(x,y),…], label, label_at, arrow)` 折线：用于把多条错误分支汇入同一竖直通道；
  `arrow=False` 表示该条只是汇入通道、末端不加箭头（汇入点不需要箭头，加了会难看）。

**版式默认值**（见 `FLOW_STYLE`）：

| 参数 | 值 |
|---|---|
| 页面 | 由内容自动定（`fit_page`），图4-2 为 8.27 × 8.97 英寸 |
| 主列 | x = 3.00；处理框 2.60 × 0.62；判断菱形 2.90 × 1.05；起止 1.80 × 0.52 |
| 错误列 | x = 6.35（宽 2.10）；汇入通道 x = 7.85 |
| 竖间距 | 相邻节点留 0.26～0.37 英寸 |
| 分支标签 | `是` / `否`，11.5 磅 |

**简化原则**（用户明确要求「小模块能简则简」，已写进流程）：

- 单主列自上而下，错误处理放右列，最后汇入**同一个**「结束」；
- **不画重试回环**（登录失败回填重输那种），失败路径直接结束，避免长回线交叉；
- 只保留必要判断（图4-2 只用 2 个），节点控制在 10 个上下，文字全部中文短句。

**流程图额外自检要点**：连线端点必须落在对应图元的边上（`v`/`h` 自动算，`poly` 要人工核对）；
菱形与平行四边形内的文字必须装得进图形的**内接矩形**（菱形内接矩形约为 0.5W × 0.5H）。

## 三、参数与换算

### 3.1 页面

| 参数 | 默认 | 说明 |
|---|---|---|
| 页面 | A4 纵向 8.27 × 11.69 英寸 | 与论文页心等比，便于整幅插入 |
| 插入宽度 | **15.5 cm**（页心宽 = 21 − 2.5 − 2.5 − 0.5 装订线） | 图按此宽度插入，缩放系数 k = 15.5/21.0 = **0.738** |
| 单页可用高 | 约 23.5 cm（正文区 24.7 cm 减图题） | 图高不得超过，否则会跨页 |

**长宽比硬约束**：`图高 / 图宽 ≤ 23.5 / 15.5 = 1.52`，否则按页心宽插入后超出一页。
A4 纵向为 1.414，安全；若内容偏长，优先压缩行距或减少消息条数，**不要**改页面宽度。

### 3.2 字号换算（关键）

```
插入后字号 = Visio 内字号 × 0.738
```

- 要求插入后 ≥ 小五（9 磅）→ Visio 内 **≥ 12.2 磅**。
- 默认：消息文字与生命线名称 **12.25 磅**（插入后 9.04 磅）、英文副名 8 磅、组合片段标签与条件 11.5 磅。
- 所有图表在交付说明里必须写出“按 15.5 cm 插入后的实际字号”，让用户知道图会不会太小。

### 3.3 版式默认值（A4 纵向）

| 参数 | 值 | 说明 |
|---|---|---|
| 生命线间距 | 1.28 英寸 | 6 条生命线：x = 0.92, 2.20, 3.48, 4.76, 6.04, 7.32 |
| 生命线表头 | 宽 1.24 × 高 0.64 英寸，白底黑框 | 两行：中文名 + 英文类名；**表头文字宽必须 ≤ 1.16 英寸**否则 Visio 折行 |
| 表头下留白 | 自动 = 消息文字高 + 0.06 英寸 | 首条消息文字在箭线上方，留白不足会压住表头（已踩过） |
| 消息行距 | 0.335 英寸（自调用 0.50） | 12.25 磅文字高约 0.23 英寸 |
| 组合片段 | 进入留 0.50、退出留 0.08 英寸；标签页 0.46 × 0.24 英寸 | 标签带必须整条高于首条消息文字 |
| 激活条 | 宽 **0.08** 英寸，白底黑框 | 越窄留给文字的空间越大；起止各留 0.12 英寸余量 |
| 自调用 | 环宽 0.28、环高 0.22、文字偏移 0.34 | 文字左对齐，紧随环右侧 |
| **连线包围盒高度** | **0.19685 英寸（5 mm）**，照抄 Visio UML「消息」主控形状 | **绝对不能为 0**，见 §7 踩坑记录 |
| 线宽 | 0.0104 英寸（0.75 磅） | 全图统一，不得用粗细分层 |

### 3.4 文字宽度预算（生成前必须逐条核算）

12.25 磅下：中文 1 字 = 0.170 英寸；西文按 Times New Roman 宽度表逐字符累加（引擎内置）。

| 位置 | 可用宽度 | 折算上限 |
|---|---|---|
| 相邻生命线之间（两端都有激活条） | 1.28 − 0.08 = **1.20 英寸** | **7 个汉字**（6 个最稳） |
| 跨 2 档以上的消息 | 取最宽空档 | 9～12 个汉字 |
| 组合片段条件文字 | 0.89 → 2.16（前端页面激活条左沿）= **1.27 英寸** | **6～7 个汉字**（8 字起就会压激活条） |
| 自调用文字 | 间距 − 0.34 − 0.04 | **4 个汉字** |
| 生命线表头 | 1.24 − 0.08 = 1.16 英寸 | 中文 6 字 / 西文 14 字符 |

引擎的 `place_x()` 会把跨档消息的文字自动放进箭头范围内**最宽的空档**（避开激活条）；
若最宽空档也放不下，才退回箭头中点——此时自检会报“文字压住激活条”，必须改短文字。

### 3.5 自检项（check_figure.py 已实现）

1. 包完整性：XML 合法、内容类型齐全、关系目标可解析；
2. 线条匀称：全图 `LineWeight` 唯一；箭头类型合法；线色为黑；
3. 字体：西文恒为 Times New Roman、中文恒为 SimSun；
4. 连线几何：**统计命中数量**（为 0 直接判失败），逐条校验 `Angle = atan2(dy,dx)`（弧度）、`Width = 线段长` 且为正、
   `Height > 0`、几何写在 `Height*0.5` 中线上、`LinePattern ≠ 0`；
5. 文字互不重叠（按**字形框**，非文本框）；
6. 文字不压激活条、不压生命线表头、不跨越组合片段框线；
7. 表头文字不超宽（防折行）；
8. 页面长宽比、插入后图高、插入后字号；
9. 图名格式（图序 + 半角空格 + 图名）且图名无标点。

## 四、Visio 文件实现要点（引擎已处理，改引擎时必看）

- 包结构沿用真实 Visio 文件：`[Content_Types].xml`、`_rels/.rels`、`visio/document.xml`、`visio/pages/pages.xml`、`visio/pages/page1.xml`、`visio/windows.xml`、`docProps/*`。模板见 `assets/visio-template.vsdx`。
- 页面部件根元素是 `<PageContents>`（**不是** `<Page>`）。
- 文字行内换行用 `\r\n`；段落用 `<pp IX='n'/>`。
- 中文靠 `<Cell N='AsianFont' V='SimSun'/>`，西文靠 `<Cell N='Font' V='Times New Roman'/>`。
- 字号单位为英寸：`Size = 磅值 / 72`。
- **Cell 的 `V` 必须是数值，公式只能放在 `F` 里。**（最容易致命的一条，见 §7.1）
  几何坐标要在生成时算好、写成数字：`<Cell N='X' V='3.200000'/>`；
  要保留公式就必须两者都给：`<Cell N='X' V='3.2' F='Width*1'/>`。
  **绝不能**写 `<Cell N='X' V='Width*1'/>`（只有 V 没有 F）。
- **1-D 连线的正确写法**（照抄 Visio 自带 UML「消息」主控形状，缺一不可）：
  - `Width = 线段长度`（恒正）、**`Height = 0.19685`（5 mm，恒正，绝不能是 0）**
  - `Angle = atan2(dy, dx)`（**弧度**）、`LocPinX = Width/2`、`LocPinY = Height/2`
  - `BeginX/BeginY/EndX/EndY` = 两端点，`PinX/PinY` = 两端点中点，`ResizeMode=0`
  - **Geometry 画在包围盒纵向中线上，且写成数值**：`MoveTo(0, 0.098425)` → `LineTo(长度, 0.098425)`
  - `NoFill=1`、`NoLine=0`、`FillPattern=0`、`LinePattern` 必须非 0（1 实线 / 2 虚线）
  - 不写 `NoShow`/`NoSnap`/`NoQuickDrag`（已知能出图的文件里没有，少写少错）
  - 每个 `<Shape>` 带 `LineStyle='3' FillStyle='3' TextStyle='3'`（容器模板里 ID 3 = Normal，即默认样式）
- 箭头：`EndArrow=1` 实心（同步消息）、`EndArrow=2` 空心（返回消息）。
- 生命线虚线：`LinePattern=2`；实线为 1；无线条为 0。填充无 = `FillPattern=0`，白底 = `FillPattern=1` + `FillForegnd='#FFFFFF'`。
- 文本框防换行：文本框宽度按估算字宽 + 0.10 英寸给足，宁可宽于内容。
- **PNG 预览必须混排字体**：西文用 `times.ttf`、中文用 `simsun.ttc`，否则预览里的西文会比 Visio 实际宽约 20%，导致误判超宽。引擎已按 `Font/AsianFont` 规则混排。

## 五、已知限制（必须向用户说明）

- 本机 LibreOffice 工具链**不支持 vsdx**（报 `unsupported-format`），**无法把 vsdx 渲染出来做像素级校验**。
- **本机 Visio 也无法用于自动校验**（Office16，装了 Visio）：通过 COM 自动化时
  `Documents.Open()` 会**永久挂起**——用「已知能正常出图」的 vsdx 做对照同样挂起，所以不是文件的问题；
  `Page.Export()` 也挂起；`Document.SaveAs()` 抛 `0x86DB03E7`。结论：**不要指望用 Visio COM 做校验或生成**。
- 替代校验：① XML/包完整性；② 连线几何自洽（角度/长度/包围盒非退化）；③ 用同一套坐标数据另绘 PNG 作为版式预览。
  三者都过**不等于** Visio 里一定零瑕疵，交付时必须如实说明并请用户在 Visio 中打开确认。
- Visio 中若虚线生命线显示为实线，检查 `LinePattern`；若连线整体不显示，先查 `Height` 是否为 0。

## 七、踩坑记录（都是真踩过的，别再犯）

### 7.1 把公式写进 `V` → Visio 里所有图形和线全部消失（只剩文字）★最致命

VSDX 里 `<Cell>` 的语义是：**`V` = 计算结果，`F` = 公式**，二者必须一致。

```xml
<!-- ✗ 错：没有 F，V 是字符串 "Width*1"，Visio 读不出坐标 -->
<Row T='LineTo' IX='2'><Cell N='X' V='Width*1'/><Cell N='Y' V='Height*0.5'/></Row>
<!-- ✓ 对：生成时按该图形实际宽高算好数值 -->
<Row T='LineTo' IX='2'><Cell N='X' V='3.200000'/><Cell N='Y' V='0.098425'/></Row>
```

症状极具迷惑性：**文字的位置、字号、内容全对，但矩形/菱形/平行四边形的边框和所有连线一个都不显示**——
Visio 解析不出 `V` 的坐标就丢掉整段 `Geometry`，而 `PinX/PinY/Text` 正常，所以只剩文字。

对照证据：本工作区**确认能在 Visio 出图**的 `系统总体用例图.vsdx` 里几何坐标全是数值
（`<Cell N="X" V="3.2"/>`）；`功能结构图(1).vsdx` 用 `V="0.3" F="Width*1"`（V 和 F 都有）。
生成器必须**为每个图形单独算好几何数值**再写 XML（引擎的 `geom_rect/geom_line/geom_diamond/geom_parallelogram` 即如此）。

### 7.2 连线 `Height = 0` → 连线消失

1. **连线 `Height = 0` → Visio 里整条线消失。** 退化包围盒会让 Visio 丢弃连线几何，用户看到「只有文字和框，线没了」。
   证据：本工作区里两张**确认能在 Visio 出图**的 vsdx（`系统总体用例图.vsdx`、`系统总体用例图_新就业群体友好驿站.vsdx`）
   中每一条连线 `Height` 都非 0（水平连线为 5 mm，来自主控形状），而 `Height=0` 的 `功能结构图(1).vsdx` 无法佐证可渲染。
   Visio 自带 UML「消息」主控形状本身也是 `Height=5mm` + 几何在中线。
2. **自检脚本的正则必须核对命中数量。** 曾出现 `re.finditer(...)` 因把 `NameU` 写在开头标签里而**一条都没匹配到**，
   循环空转、`bad=0`，于是「全部通过」其实是**什么都没查**。凡遍历类检查，必须统计命中数并在为 0 时报错。
3. **PNG 预览必须中西文混排**（西文 `times.ttf`、中文 `simsun.ttc`），否则预览里的西文比 Visio 实际宽约 20%，会误判超宽。
4. **组合片段的条件文字起点在 x=0.89**，前端页面激活条左沿在 x=2.16，所以条件最多 7 个汉字，8 个就会压条。
5. **首条消息文字在箭线上方**，表头下留白必须 ≥ 文字高 + 0.06 英寸，否则会压住表头框。
6. 生命线表头文字宽必须 ≤ 表头内宽（1.24 − 0.08），否则 Visio 会折行。
